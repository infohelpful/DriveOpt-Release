# DriveOpt

C: 용량을 확보하는 Windows 유틸입니다.

이 저장소에는 **완성된 zip만** 올립니다. 소스 코드는 [DriveOpt](https://github.com/infohelpful/DriveOpt)에 있습니다.

## 다운로드

[Releases](https://github.com/infohelpful/DriveOpt-Release/releases)에서 최신 `DriveOpt-*.zip`을 받으세요.

## 실행 방법

1. zip을 **폴더째** 압축 해제합니다. `DriveOpt.exe`만 따로 복사하면 실행되지 않습니다.
2. 폴더 안의 `DriveOpt.exe`를 실행합니다.
3. 관리자 권한 확인이 뜨면 **예**를 선택합니다.

## 필요한 환경

- Windows 10 또는 Windows 11 (64비트)
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Windows App Runtime 1.7](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads)

## 기능

- **프로그램 이동**: 폴더를 다른 드라이브로 옮긴 뒤, 원래 경로를 실제 폴더에 연결합니다.
- **용량 찾기**: 디스크에서 용량이 큰 폴더와 파일을 찾습니다.
- **용량 정리**: 임시 파일과 Windows가 잡아 둔 용량을 정리합니다.
- **용량 압축**: zip으로 묶지 않고, 디스크가 쓰는 용량만 줄입니다.
